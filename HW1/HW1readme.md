
# Homework Question

A professor wants a Python program that calculates a student’s final grade based on several parts of the course.

The course grade is made up of:

- Homework: 20%
- 3 Quizzes: 15%, each 5%
- Midterm Exam: 25%
- Final Exam: 30%
- Participation: 10%

## Write a Python program that:

1. Stores each score in a variable based off a prompt written by you.

2. Calculates how much each category contributes to the final grade using the percentages above.

3. Adds the weighted scores together to calculate the student’s final numerical grade.

4. Uses if, elif, and else statements to determine the student's letter grade using this scale:

    - 90 or above = A
    - 80–89.99 = B
    - 70–79.99 = C
    - 60–69.99 = D
    - Below 60 = F

5. Prints the student's final numerical grade and letter grade.

Your program should work if the scores stored in the variables are changed. Do not manually enter the final grade or letter grade into the output.

## What the question assess:

The problem helps assess whether a student understands variables, arithmetic, percentages, and conditional statements in Python. They will have to take several pieces of information to calculate the final result.
